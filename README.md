1. **앱 설치**:
   - **아이폰 (iOS)**: App Store에서 `ntfy` 검색 후 설치
   - **갤럭시 (Android)**: Google Play 스토어에서 `ntfy` 검색 후 설치
2. **채널 구독 (1번만 클릭)**:
   - `ntfy` 앱 실행 후 우측 하단 **`+` (구독 추가)** 버튼 터치
   - 토픽 이름에 **`briefing-hellouou`** 입력 후 **구독(Subscribe)** 터치!
3. **완료**:
   - 매일 오전 06:00에 컴퓨터가 브리핑을 수집하는 즉시 스마트폰 화면에 **"📊 [날짜] 모닝 경제·증시 & 신문 1면 브리핑"** 팝업 알림이 뜹니다.
