## ⏰ 이중 자동 실행 스케줄러 (로컬 + 클라우드 무중단)

본 시스템은 **컴퓨터가 꺼져 있든 켜져 있든 365일 무중단으로 동작**하도록 2중 스케줄러 체계로 구축되어 있습니다:

### 1. ☁️ GitHub Actions 클라우드 스케줄러 (메인)
- **실행 위치**: GitHub 클라우드 서버 (컴퓨터 전원 OFF 상태에서도 100% 작동)
- **설정 파일**: [`.github/workflows/briefing.yml`](.github/workflows/briefing.yml)
- **실행 주기**: 매일 한국 시간 06:00 (UTC 21:00) 정각
- **동작**: 클라우드 가상환경에서 뉴스와 지표를 수집하고, 최신 웹페이지(`index.html`)를 자동 커밋·배포한 뒤 스마트폰으로 `ntfy` 푸시 알림을 발송합니다.

### 2. 💻 Windows 로컬 작업 스케줄러 (백업)
- **실행 위치**: 사용자 로컬 PC (`DailyEconomicBriefing`)
- **실행 주기**: 매일 오전 06:00 (Daily)
- **절전 모드 자동 해제 (WakeToRun)**: 컴퓨터가 절전 모드일 때 스스로 화면을 깨워 작업을 수행합니다.
- **부재 시 자동 보정 (StartWhenAvailable)**: 컴퓨터가 완전히 꺼져 있었더라도, 아침에 PC 전원을 켜는 순간 놓친 작업을 감지하여 즉시 백그라운드에서 실행합니다.
